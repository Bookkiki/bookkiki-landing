ElevenLabs 음성 답변 변환

문서 code: overseas_elevenlabs_stt_consent · 버전: 2026-09-26

각 기능의 국외 이전은 별도로 동의받아야 합니다. 회사 저장소의 삭제기한과 공급자 보유기간은 다릅니다.

이전받는 자·연락처 국가 이전 항목 목적 시점·방법 공급자 보유기간
Eleven Labs Inc. (legal@elevenlabs.io) 미국(보관). 호스팅·서버는 미국·네덜란드·싱가포르 자녀 음성(요청 입력), 변환된 text(공급자 처리·응답) 음성을 text로 변환 보호자가 녹음 전송을 확정한 뒤 변환 요청 시 암호화 전송 초기 운영 STT는 non-ZRM(enable_logging=true) 방식으로 요청 이력에 입력·결과가 보관된다. 계정에서 이력을 삭제하면 해당 음성·text는 공급자 DB에서 즉시 제거되지만 debugging·moderation log는 남을 수 있고 backup에는 최대 30일 남을 수 있다. 공급자는 음성에 관해 생성한 데이터를 마지막 상호작용 후 3년을 넘겨 보관하지 않는다. Zero Retention Mode는 공급자가 기업 계약 고객에게만 제공하므로 적용되지 않는다.

2026-09-15 운영 계정 시험에서 enable_logging=false 요청은 HTTP 403, true 요청은 HTTP 200이었다. 초기 STT에 ElevenLabs ZRM이 적용된다고 고지하지 않는다. ElevenLabs는 non-ZRM 요청 이력 삭제 API를 제공하지만, 현재 Server는 이 API를 호출하지 않는다. 회사 저장소의 24시간 원본 삭제 정책은 ElevenLabs 사본의 보유기간이 아니다.

동의를 거부하면 직접 text로 답할 수 있습니다.

동의 문구: ElevenLabs 음성 답변 변환을 위한 국외 이전에 동의합니다.

철회와 삭제

각 동의는 앱 설정에서 개별 철회할 수 있습니다. 철회 시 해당 목적의 새 전송과 대기·재시도 작업을 즉시 차단합니다. 회사는 회사 저장소의 관련 정보를 별도로 고지한 기간 안에 삭제하고, 공급자 사본은 공급자별 삭제 요청 방식·기산점·예외와 처리기간에 따라 처리합니다.
