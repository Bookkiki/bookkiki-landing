OpenAI OpCo, LLC (privacy@openai.com) 미국 및 OpenAI 재수탁자 처리 국가. 현재 코드는 별도 지역 API endpoint를 사용하지 않음 자녀 애칭·관심사·읽기 수준·인터뷰 요약, 기록이 있는 경우 이름·성별·나이, 캐릭터 이미지, 선택한 연출 설정(mood·고정 제목·피할 소재), 생성된 동화 text·삽화(후속 생성·검수 단계) 개인화 동화·삽화 생성 보호자가 동화 생성을 확정한 뒤 생성 요청 시 암호화 전송 Bookkiki 운영 project에는 ZDR/MAM이 적용되지 않았다. Langfuse GmbH (Oranienburger Straße 91, 10178 Berlin, Germany / privacy@clickhouse.com) 아일랜드 (Langfuse Cloud EU region, AWS eu-west-1) 가명 처리한 동화 session ID·자녀 식별자, 쪽수·화풍·읽기 수준·생성 언어, 호출 종류와 모델명, 토큰 사용량, 소요 시간, 검수 차단 사유 코드, 재생성 횟수, 프롬프트 이름·version, 검수·심사가 판정 근거로 적은 자유 서술(자녀 캐릭터의 외모 특징 묘사가 포함될 수 있음) 동화·삽화 생성과 검수의 품질·비용·장애 분석 위 OpenAI 호출이 끝난 뒤 책 한 권 단위로 암호화 전송 회사가 쓰는 무료(Hobby) 요금제의 보관기간은 30일이며, 그 뒤 trace·observation·점수는 자동 삭제된다. 그 전에 삭제하려면 privacy@clickhouse.com으로 요청한다. Prompt Management에 저장하는 생성 지시문은 아이 정보를 담지 않으며 보관기간 대상이 아니다.

관측에는 프롬프트 원문, 생성된 동화 본문, 삽화 이미지, 자녀의 이름·생년월일을 보내지 않습니다. session·자녀 식별자는 원본 UUID가 아니라 회사만 아는 키로 계산한 가명값이며 되돌릴 수 없습니다.

다만 판정 근거의 자유 서술은 예외입니다. 삽화가 캐릭터와 같은 아이로 보이는지, 앞뒤 쪽이 이어지는지를 심사한 결과를 사람이 읽을 수 있는 문장으로 남기기 때문에, "머리 모양·머리 색·피부·옷" 같은 자녀 캐릭터의 외모 묘사가 그 문장에 들어갑니다. 이 서술이 없으면 어떤 삽화가 왜 다시 그려졌는지 확인할 수 없어 품질·비용 분석과 장애 대응이 불가능하므로 이전 항목에 명시해 고지합니다. 동의를 철회하면 이후 생성과 함께 이 서술의 전송도 멈춥니다.

동화 원고 Worker는 선택된 연출 설정과 character_kind·character_likeness_stage도 생성 요청 데이터에 포함합니다. 선택된 자유 text에는 보호자가 입력한 개인정보가 포함될 수 있습니다. 이름·성별·나이는 기록이 없으면 요청에 넣지 않습니다.

동의를 거부하면 AI 동화·삽화를 만들 수 없습니다.
