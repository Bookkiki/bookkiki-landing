(legal@elevenlabs.io) 미국(보관). 호스팅·서버는 미국·네덜란드·싱가포르 인터뷰 질문 text 또는 동화 낭독 text 질문과 동화의 음성 합성 보호자가 낭독 기능을 활성화한 뒤 음성 생성 요청 시 암호화 전송 질문 TTS와 동화 낭독 모두 요청 이력 보관 방식(enable_logging=true)으로 호출한다. 이력은 공급자 API로 삭제할 수 있고 삭제 후 debugging·moderation log 잔존과 backup 최대 30일은 위와 같다. 공급자는 음성에 관해 생성한 데이터를 마지막 상호작용 후 3년을 넘겨 보관하지 않는다.

생성 음성은 공급자 응답입니다. 질문 TTS와 동화 낭독 TTS는 호출 주체와 logging 설정이 다릅니다. STT의 non-ZRM 운영 결정이 두 TTS 경로의 공급자 보관 조건까지 확정한 것은 아닙니다.

동의를 거부하면 질문과 동화를 화면의 text로 이용할 수 있습니다.
